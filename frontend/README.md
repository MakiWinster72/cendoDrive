# CendoDrive 前端

Vue 3 + Vue Router + Axios。账号认证、文件列表、文件夹管理、重命名、移动、回收站和下载使用真实 Spring Boot 接口；文件预览复用已认证的下载接口。分片上传、复制、收藏、隐藏空间、详情、按类型整理、容量统计、限时分享和跨用户独立转存均已接入真实后端接口。传输列表展示本次页面会话内的上传与下载任务。

## 本地运行

建议使用 Node.js 24 LTS（PDF.js 要求 Node.js `>=22.13.0 || >=24`）。先按 `backend/README.md` 启动 MySQL、Redis、FastDFS 和后端（默认 `http://localhost:8080`），然后在 `frontend/` 运行：

```bash
npm ci
npm run dev
```

打开 `http://localhost:5173`。Vite 开发服务器把 `/api` 请求原样代理到后端 8080，不必为本地开发开启宽泛 CORS。后端停止时登录会报网络错误，不存在演示 Token 回退。

如需连接其他部署环境，可复制 `.env.example` 为本机 `.env`，设置完整的 `VITE_API_BASE_URL`；生产环境应由部署方提供同源 `/api` 反向代理，或明确配置安全的 CORS 允许源。不要将任何凭据写入 Vite 环境变量，它们会暴露在浏览器中。

```bash
npm run build
```

## 文件管理与容量

- 桌面工具栏、移动端根目录及文件夹内页右上角的「更多操作」菜单均可「新建文件夹」，直接在当前列表 / 网格中插入输入行，不再使用 `prompt` 或创建弹窗。默认名称自动避开已加载的同名项目；进入编辑时自动聚焦并选中名称。
- 移动端进入文件夹后使用独立的搜索栏、路径导航和圆角列表面板；左上角返回上一级，点击「我的网盘」返回根目录，路径中的祖先目录也可直接进入。桌面面包屑同样支持逐级返回。导航清空搜索、选择和未提交草稿；加载失败保留当前目录并可重试，请求期间禁止重复导航。
- 移动文件页右上角统一使用小尺寸上下箭头（传输列表）和三个点（更多操作），不直接显示新建按钮。箭头进入既有 download 传输列表，默认选中下载，返回保留当前目录、搜索和排序；真正排序仍在列表上方。传输页只复用 `page/download` 的必要组件，记录本次页面会话中的真实文件下载及进度，不插入示例任务。
- 文件夹内页支持名称 / 修改时间 / 大小排序，以及列表 / 网格切换；「更多操作」可新建目录或选择文件。
- 普通文件页和图片 / 视频 / 文档 / 音频 / 其他分类使用服务端文件名搜索，不依赖已加载目录缓存。根目录默认全网盘，进入文件夹默认当前目录及所有子目录，可随时切换范围和类型；每页 20 项，排序作用于全部结果。关键词去除首尾空格，最长 100 字符，输入防抖 250 ms，取消请求并隔离过期响应。
- 搜索结果显示所在路径，文件点击可预览、文件夹点击可进入，「所在目录」可直接定位到尚未加载的目录并逐级返回。搜索失败提供重试；退出搜索还原普通目录列表。桌面和移动端同一时刻只发起一组搜索，不把搜索结果混入目录缓存。
- 所有格式（含图片、扫描 PDF、文档）**只匹配文件名**，不读取正文、不做 OCR；隐藏空间、回收站及其后代不参与服务端搜索。收藏、最近、隐藏空间和回收站页保留当前已加载列表的文件名筛选，不替换为全网盘搜索。
- 重命名直接替换项目原位置的名称；桌面可从「文件操作」选择重命名，或聚焦列表行 / 网格卡片后按 F2，移动端可从选择操作区进入。文件默认只选中最后一个扩展名前的主文件名，文件夹选中完整名称。
- Enter / 勾号保存，Esc / 叉号取消；未修改名称不会发送重命名请求。空名称、路径分隔符、超长名称及服务端同名冲突在原行提示并允许修改后重试；请求期间禁止重复提交。切换目录、分类、搜索或移动端页面会撤销未提交的草稿，不偷偷保存。
- 移动 / 复制面板也可直接在所选位置插入新建目录输入行，不再叠加第二个弹窗；创建成功后自动选中新目录，直接确认操作。输入时按 Esc 只取消新建，不关闭目标选择面板。

- 桌面行尾「文件操作」或多选后的「更多操作」，以及移动端选择文件后的操作面板，可移动、复制、收藏 / 取消收藏、移入 / 移出隐藏空间、查看详情、按类型整理、重命名和移入回收站。
- 移动 / 复制按完整路径和目录 ID 选择目标，同名文件夹不再混淆；自身与子目录不可作为目标。后端检查所属用户、同名冲突、回收站状态和容量，失败不会显示成功。
- 我的收藏与隐藏空间使用独立服务端列表；隐藏项目及其后代不出现在普通列表和最近文件。隐藏仅是显示标记，不是加密或密码保护。
- 「按类型整理」按扩展名归类，不是 AI 整理；执行前确认，文件夹不移动，同名项目不覆盖。
- 桌面侧栏和移动端文件页展示真实已用、总量和可用容量；复制、上传、回收站操作后刷新。回收站仍占容量，进行中的上传预留容量；统计失败显示错误和重试，不回退为演示数字。
- 大于 100 MiB 的文件使用持久化分片接口；重新选择相同文件可续传缺失分片。取消仅终止客户端请求，服务端未完成任务默认保留 24 小时。

测试还覆盖完整路径选择、操作确认、标记双向切换、错误重试、移动端入口、详情纯文本显示及容量刷新，以及行内编辑的焦点、扩展名选中、中文输入法、重复提交保护、导航取消和 767 / 768px 断点切换。

## 文件预览

在桌面文件列表点击文件名或双击文件行、点击网格文件，或在移动端点击文件行 / 最近文件，即可打开预览；文件夹仍进入下一级，回收站不打开预览。关闭按钮、Escape 和点击弹窗外部可关闭预览，移动端使用全屏布局。

| 类型     | 支持范围                                         | 预览大小上限 |
| -------- | ------------------------------------------------ | ------------ |
| DOCX     | 正文、表格、内嵌图片                             | 20 MiB       |
| PDF      | 本地画布渲染、上一页 / 下一页                    | 100 MiB      |
| 图片     | JPG/JPEG、PNG、GIF、WebP、BMP、AVIF、SVG         | 100 MiB      |
| 视频     | MP4、M4V、MOV、WebM、OGV；带播放控件，不自动播放 | 100 MiB      |
| 文本     | TXT；UTF-8、带 BOM 的 UTF-16、GB18030 回退       | 5 MiB        |
| Markdown | MD / Markdown；阅读与源码切换                    | 5 MiB        |

- 通过 `GET /api/files/{id}/download` 携带现有 Bearer Token 获取文件，后端继续校验所有者和文件状态；不生成公开链接、不将 Token 放进 URL，不使用第三方在线预览服务。
- 当前先完整获取文件 Blob，再进行本地解析；视频不是流式播放，PDF 不是 Range 按需加载。超限或不支持的文件会显示下载入口。视频容器、编码和图片格式能否播放仍取决于浏览器支持。
- DOCX 使用 Mammoth，侧重内容而非 Word 原始分页和复杂排版；旧版 `.doc` 不支持。PDF 为画布预览，不支持文字选择、搜索和密码输入；加密、损坏文件提示下载后查看。
- Markdown / DOCX 输出经 DOMPurify 白名单清理，屏蔽脚本、交互表单、外链和远程图片，仅允许支持的内嵌栅格图片。TXT / Markdown 源码作为纯文本显示。
- 关闭或切换文件会取消请求并释放对象 URL、PDF 渲染任务，同时恢复页面滚动。错误可重试，也可下载原文件。
- `npm run dev` / `npm run build` 自动复制 PDF.js 字体、CMap 和 WASM 到 `public/pdfjs/`（生成目录不提交）；部署时需保留构建产物中的 `pdfjs/` 和 worker 文件。

```bash
npm test
npm run build
```

测试覆盖格式判定、大小限制、鉴权请求、文本解码、HTML 清理、真实 DOCX 内容，以及弹窗加载、重试、切换、关闭和资源释放。

## 样式与响应式约定

- `src/styles/main.css`：全局基础、桌面/移动布局切换、文件页基础和共用导航。
- `src/styles/home.css`：移动首页专属规则；个人页、分享页等继续使用各自的样式文件。
- 页面专属规则不要在 `main.css` 重复定义；将基础属性和页面调整合并到所属文件，避免靠导入顺序覆盖。

| 屏幕宽度                  | 名称          |
| ------------------------- | ------------- |
| `< 640px`                 | Mobile        |
| `640px ≤ width < 768px`   | Small         |
| `768px ≤ width < 1024px`  | Tablet        |
| `1024px ≤ width < 1280px` | Laptop        |
| `1280px ≤ width < 1536px` | Desktop       |
| `≥ 1536px`                | Large Desktop |

首页在 `< 768px`（Mobile / Small）使用移动布局，`≥ 768px` 使用桌面布局。Tablet 使用紧凑侧栏和文件列；更宽屏幕沿用弹性桌面布局，不为每个档位添加空媒体查询。使用 CSS 范围语法（如 `@media (width < 768px)`），确保恰好 768px 时不会同时命中移动端规则。360px / 380px 等窄屏微调不属于布局切换断点。

## 分享行为

- 私有文件页创建 1 / 7 / 30 天有效的单文件链接；“我的分享”仅列出本人的记录，并可撤销。文件夹分享暂不支持。
- `/share/:token` 可匿名查看和下载；公共请求使用不带 Bearer Token 的独立客户端。失效、撤销或源文件不可用时显示分享失效提示。
- 未登录点击“登录后转存”会进入登录页，成功后返回原分享；需再次点击转存，不自动复制文件。登录用户点击“转存到我的网盘”会独立保存到自己的根目录，并显示成功反馈及网盘入口；同名文件不覆盖，会提示先重命名。
- 已转存副本不受分享到期、撤销或原文件删除影响。页面防止重复转存并取消过时的分享摘要请求；下载的 JSON Blob 错误也会显示明确的失效信息。

## 认证行为

- 注册使用用户名（3–64 位字母、数字、下划线）、密码（8–128 位）和可选昵称；成功后跳转登录，不自动登录。
- 登录只接受用户名和密码。勾选“下次自动登录”将会话存于 localStorage；不勾选时存于 sessionStorage。两者都不会延长后端 Token 的 24 小时有效期。
- 刷新或打开私有页面时通过 `/api/user/me` 验证保存的 Token，验证前不会展示文件页面。退出调用 `/api/auth/logout` 撤销当前 Token，然后清理本地会话；若网络故障，会提示服务端撤销未确认。
- 浏览器存储中的 Bearer Token 可被同源恶意脚本读取；正式上线需评估 XSS/CSP、HTTPS、依赖安全和更适合生产的会话方案。
- 找回密码、扫码和第三方登录尚未实现；会员及推广展示仍是静态数据。

## 账号管理

- 移动端“我的 → 账号管理”或头像，桌面端右上角设置 / 用户菜单进入。返回保留原页面；资料加载和保存失败可重试，不显示假成功。
- 昵称保存同步本地会话显示，不改用户名 / 用户 ID、不延长 Token 有效期。头像可上传 / 移除，限制为 PNG / JPEG、2 MiB、2048×2048；服务端统一保存为 256×256 PNG。
- 改密必须输入当前密码并重复新密码；新密码 8–72 字符且最多 72 个 UTF-8 字节。成功后所有设备旧会话失效，当前页面清理私有文件和传输状态，返回登录页。当前密码错误不会误退出。
- 查找用户只按完整用户名精确匹配，返回 ID、用户名、昵称及头像标记；不建立好友关系，也不自动分享。
- 注销需再次输入密码和“注销账号”。成功后立即退出并撤销本人分享，账号与文件先保留 7 天；到期后自动物理清理，故障会重试。登录页“恢复 7 天内注销的账号”验证原密码恢复，然后重新登录；旧分享 / Token 不恢复。这不是忘记密码找回流程。

接口和清理时机见[账号管理接口文档](../docs/账号管理接口文档.md)。页面全程使用自有后端，无第三方头像存储。账号相关测试还覆盖忙碌时防重复提交、Escape 返回、头像 URL 释放、查询竞态及账号数据清空。

## 传输列表

- 移动端：首页右上角“传输列表”按钮，或“我的 → 转存与下载”；桌面端：左侧“传输”。
- 上传选择文件后进入等待队列；开始上传后同步普通上传/分片上传的准备、进度、成功、失败和取消状态。关闭上传面板、打开或退出传输列表不会终止上传。
- 下载复用真实文件下载接口，默认同时下载 2 个，可选择 1 / 2 / 3 / 5 个。没有响应总长度时不伪造进度；成功表示响应已接收并交给浏览器保存，最终目录及保存结果由浏览器控制。
- 下载和上传各自提供全部、已完成、进行中、任务失败筛选；取消任务归入失败筛选。按任务创建日期分组，记录仅保存在当前页面会话内，刷新不恢复传输。
- “全部清除”仅清理当前类型的已结束记录，不删除网盘文件、不取消等待或进行中的任务。清除的上传记录不会被上传面板重新同步，主动重试会重新显示。
- 转存、云添加、会员加速、推广领取、下载券使用及右上角批量选择/设置保留为无操作展示按钮。

验证：`npm test` 和 `npm run build`。新增 `src/stores/transfers.test.ts` 覆盖并发调度、进度、失败与清理；`src/components/TransferPage.test.ts` 覆盖模板编译、品牌及假按钮。
