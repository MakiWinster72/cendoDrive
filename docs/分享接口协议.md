# 文件分享接口协议

分享 Token 是 32 位十六进制随机访问凭据，不是用户 ID。所有者可以自行选择是否设置提取码和有效期；本阶段没有指定访问者、好友或聊天功能。

前端调用 `/api`（或 `VITE_API_BASE_URL`）。分享链接为 `${location.origin}/share/${token}`，指向前端路由。**不将提取码放入 URL、查询参数或浏览器持久存储**。成功直接返回 DTO，错误为 `{code,message,fields}`。

## 创建、列表与撤销

| 接口 | 身份 | 成功 |
| --- | --- | --- |
| `POST /api/shares` | Bearer；只能分享本人未隐藏、未删除的普通文件 | 201 `ShareResponse` |
| `GET /api/shares` | Bearer；仅本人记录，包含历史 | 200 数组 |
| `DELETE /api/shares/{id}` | Bearer；仅创建者，参数是分享 ID 而非 Token | 204，重复撤销幂等 |

创建示例：

```json
{"fileId":"42","expiresInSeconds":604800,"extractionCode":"Ab12"}
```

- `extractionCode` 可省略或为 `null`，表示无需提取码；设置时必须为 **4–16 位 ASCII 字母或数字，区分大小写**。空字符串不是有效码。
- `expiresInSeconds` 为 1–2592000（最长 30 天）。前端分享设置弹窗提供 1 / 7 / 30 天及自定义整数 1–30 天。
- 用户确认前不创建链接；失败保留设置可重试，创建期间防止重复提交。只有服务端成功后才显示链接。

`ShareResponse` 示例：

```json
{
  "id":"51","token":"0123456789abcdef0123456789abcdef",
  "fileId":"42","fileName":"项目方案.pdf","kind":"file","size":120,
  "createdAt":"2026-10-08T04:00:00Z","expiresAt":"2026-10-15T04:00:00Z",
  "status":"ACTIVE","hasExtractionCode":true,"extractionCode":"Ab12"
}
```

ID 以字符串返回。`status` 为 `ACTIVE` / `CANCELLED`，过期通过 `expiresAt` 判断，最终以服务端校验为准。后端同时保存用于校验的 BCrypt 散列和用于所有者回显的提取码。**创建和本人列表响应返回 `extractionCode`，不返回散列；公开详情、下载和转存响应不返回码。** 刷新页面或重新进入“我的分享”后仍可查看、单独复制提取码；复制链接继续包含“链接 + 提取码”。未设置码时 `extractionCode` 为 null，只复制链接。V14 之前只存散列的旧记录无法还原原码，返回 null，弹窗说明历史数据未保存可回显码，可使用原码或重新创建分享。

## 访客访问与转存

| 接口 | 身份 | 成功 |
| --- | --- | --- |
| `GET /api/shares/{token}` | 匿名；有保护时要求 `X-Share-Code` | 200 文件摘要和有效期 |
| `GET /api/shares/{token}/download` | 匿名；有保护时要求 `X-Share-Code` | 200 文件流 |
| `POST /api/shares/{token}/save` | Bearer；有保护时同样要求 `X-Share-Code` | 201 接收者的新文件 |

```http
X-Share-Code: Ab12
```

公开详情和下载使用独立 Axios 客户端，不附带过期的用户 Bearer。转存使用认证客户端，请求体为 `{"parentId":null}`（根目录）或接收者自己的目标目录 ID。**提取码同样校验在元数据、下载、转存三个入口，不能绕过详情直接取文件。** 未验证前不返回文件名、大小或原始存储地址。

公开详情示例：

```json
{
  "file":{"id":"42","name":"项目方案.pdf","kind":"file","size":120,
    "parentId":null,"updatedAt":"2026-10-08T04:00:00Z","deletedAt":null},
  "expiresAt":"2026-10-15T04:00:00Z"
}
```

下载由后端读取 FastDFS 并返回流，不暴露存储地址；响应包含 `Content-Disposition: attachment; filename*=UTF-8''...`。转存创建接收者自己的元数据与独立物理副本、检查配额，不覆盖同名文件；原分享撤销/过期或原文件删除不影响已经转存的副本。

未登录转存先跳转登录，回来后需要重新输入提取码并主动点击转存，不自动执行。路由切换取消旧摘要请求并清除码，避免跨分享混用。

## 失效与安全

- MySQL 保留归属、撤销、过期时间、可回显的提取码及可选 BCrypt 散列；Redis `share:access:<token>` 保存访问凭据及剩余有效期 TTL。每个访问入口同时检查数据库时间/状态、Redis 凭据、来源用户和来源文件/祖先目录。
- Token 无效、过期、撤销、来源账号注销或文件/祖先目录不可访问，统一 `404 SHARE_NOT_FOUND`。不会因为持有旧码重新激活分享；恢复账号也不恢复旧分享。
- 提取码错误按“分享 Token + 请求直接来源 IP”计数，使用 Redis 原子限流；累计 5 次错误锁定 15 分钟，返回 `429 RATE_LIMITED` 和 `Retry-After: 900`。缺失码只提示输入，不累计失败；成功验证清除此前失败次数。锁定期间正确码也不能通过。
- 不信任客户端随意提交的 `X-Forwarded-For`。反向代理部署时当前直接来源可能是代理 IP，同一分享的访客可能共用限流桶；如需真实客户端 IP，应单独配置可信代理，而不是直接采信该头。
- 正式部署强制 HTTPS，不记录完整分享 Token、提取码或 Bearer。跨源部署需要精确的 `CORS_ALLOWED_ORIGINS`，允许头包含 `X-Share-Code`；开发使用 Vite 同源代理。
- 链接和码可以被转发，并不识别“指定的人”。已下载/转存的内容无法收回；分享 Token 熵与来源状态是基础保护，提取码只是额外门槛。

## 错误码

| HTTP / code | 含义 |
| --- | --- |
| 400 `INVALID_INPUT` | 创建参数或目标目录参数非法 |
| 401 `UNAUTHORIZED` | 认证接口缺少/携带无效 Bearer |
| 403 `SHARE_CODE_REQUIRED` | 有效保护分享缺少码 |
| 403 `SHARE_CODE_INVALID` | 码格式错误或不匹配 |
| 429 `RATE_LIMITED` | 提取码错误锁定，15 分钟后重试 |
| 404 `FILE_NOT_FOUND` | 无权创建该文件的分享 |
| 404 `SHARE_NOT_FOUND` | 分享或来源已失效 |
| 409 `NAME_CONFLICT` | 接收者目标目录已有同名文件 |
| 507 `QUOTA_EXCEEDED` | 接收者容量不足 |
| 503 `SHARE_UNAVAILABLE` / `STORAGE_UNAVAILABLE` | 缓存或文件存储不可用 |

## 验收与迁移

V11 新增可空 `share_links.extraction_code_hash`；V14 新增可空 `share_links.extraction_code`，用于所有者回显。V14 之前只存散列的历史提取码无法还原，新增列保持 null；前端提示使用原码或重新创建分享。不改历史迁移，后端重启时由 Flyway 应用。覆盖三入口校验、跨用户隔离、取消、真实 Redis 锁定、过期和独立转存。

真实 MySQL / Redis / FastDFS 验收：

```sh
cd backend
sh scripts/verify-real-stack.sh
```

脚本只新建 `cendo_acceptance_*` 隔离数据库，绝不迁移/清空开发 `cendo` 库；使用现有本机 MySQL、Redis、FastDFS。覆盖注册/资料/头像/全端改密/7 天注销恢复与清理、分片上传/下载/配额、分享三入口/限流/过期/撤销/独立副本。成功清理测试账号、物理文件和专用 Redis Key 后删临时库；失败保留库和分片目录便于诊断。详见 `backend/README.md`。
