# 搜索接口文档

## 接口地址与 HTTP 方法

- 方法：`GET`
- 路径：`/api/files/search`
- 开发环境完整地址：`http://localhost:8080/api/files/search`
- 认证请求头：`Authorization: Bearer <token>`
- 参数放在 URL 查询字符串中，无请求体。成功返回 JSON，不使用额外的 `data` 包装层。

仅按当前用户的文件名（包括文件夹名）搜索，不搜索正文或 OCR 内容；排除隐藏、已删除项目及其后代，不返回其他用户的文件。

## 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `q` | string | 是 | 无 | 去除首尾空白后长度为 1～100；文件名包含匹配，不区分大小写 |
| `scope` | string | 否 | `all` | `all`：全网盘；`folder`：指定目录及所有子目录 |
| `parentId` | int64 | 否 | 不传 | 仅 `scope=folder` 可传，为目录 ID；不传表示根目录。指定目录本身不计入结果；`scope=all` 时传此参数会失败 |
| `type` | string | 否 | `all` | `all`、`folder`、`image`、`video`、`audio`、`doc`、`other`；文件按扩展名分类 |
| `sort` | string | 否 | `time` | `time`：修改时间降序；`name`：名称升序；`size`：大小降序。相同值再按 ID 排序 |
| `page` | integer | 否 | `0` | 从 0 开始，范围 0～10000 |
| `size` | integer | 否 | `20` | 每页条数，范围 1～100 |

`%`、`_`、`!` 按普通字符匹配，不作为通配符。中文和特殊字符应进行 URL 编码，例如：

```sh
curl --get 'http://localhost:8080/api/files/search' \
  -H 'Authorization: Bearer <token>' \
  --data-urlencode 'q=合同' \
  --data-urlencode 'scope=folder' \
  --data-urlencode 'parentId=10' \
  --data-urlencode 'type=doc' \
  --data-urlencode 'sort=time' \
  --data-urlencode 'page=0' \
  --data-urlencode 'size=20'
```

## 成功响应

HTTP `200 OK`，示例（搜索目录 ID 为 10 的“资料”目录）：

```json
{
  "items": [
    {
      "file": {
        "id": "42",
        "name": "合同.pdf",
        "kind": "file",
        "size": 102400,
        "parentId": "10",
        "updatedAt": "2026-09-29T06:30:00Z",
        "deletedAt": null,
        "favorite": false,
        "hidden": false
      },
      "ancestors": [
        {
          "id": "10",
          "name": "资料",
          "kind": "folder",
          "size": 0,
          "parentId": null,
          "updatedAt": "2026-09-29T06:00:00Z",
          "deletedAt": null,
          "favorite": false,
          "hidden": false
        }
      ],
      "path": "/资料"
    }
  ],
  "total": 1,
  "page": 0,
  "size": 20
}
```

### 文件 ID、文件名与其他字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | array | 当前页命中结果 |
| `items[i].file.id` | string | **文件 ID**，例如 `"42"`；不是 FastDFS 存储地址 |
| `items[i].file.name` | string | **文件名**，例如 `"合同.pdf"`，包含扩展名；文件夹则为文件夹名 |
| `items[i].file.kind` | string | `file` 或 `folder` |
| `items[i].file.size` | integer | 大小，单位字节；文件夹为 0 |
| `items[i].file.parentId` | string / null | 父目录 ID；根目录下的项目为 null |
| `items[i].file.updatedAt` | string | UTC ISO-8601 修改时间 |
| `items[i].file.deletedAt` | null | 搜索不返回已删除项目 |
| `items[i].file.favorite` | boolean | 是否收藏 |
| `items[i].file.hidden` | boolean | 搜索返回的命中项目为 false |
| `items[i].ancestors` | array | 从根到父目录的有序文件夹元数据，结构同 `file`；根目录下的项目为 `[]` |
| `items[i].path` | string | 所在目录路径，不包含命中项目自身名称；根目录为 `/` |
| `total` | integer | 权限、范围、类型、关键词过滤后的总条数，不是当前页条数 |
| `page` | integer | 当前页码 |
| `size` | integer | 请求的每页条数 |

前端读取文件 ID 用 `response.items[i].file.id`，读取文件名用 `response.items[i].file.name`，不是 `items[i].id` 或 `items[i].name`。响应 ID 为字符串，请求 `parentId` 为整数；建议保留响应 ID 的字符串形式以避免 JavaScript 大整数精度损失。

## 空结果响应

没有匹配项仍返回 HTTP `200 OK`，不是 404：

```json
{
  "items": [],
  "total": 0,
  "page": 0,
  "size": 20
}
```

如果有匹配项但请求页码超出结果范围，也返回 `200` 和空 `items`，但保留真实总数，例如：

```json
{
  "items": [],
  "total": 1,
  "page": 99,
  "size": 20
}
```

## 失败响应

业务失败响应使用 `code`、`message`、`fields`，HTTP 状态不是 200。

### 参数不合法：HTTP 400

例如 `q` 只有空白、`size=101`，或 `scope=all` 同时传 `parentId`：

```json
{
  "code": "INVALID_SEARCH",
  "message": "Invalid search parameters",
  "fields": {}
}
```

### 未登录或 Token 无效：HTTP 401

```json
{
  "code": "UNAUTHORIZED",
  "message": "Unauthorized",
  "fields": {}
}
```

### 指定目录不可访问：HTTP 404

目录不存在、不属于当前用户、已删除或位于隐藏空间：

```json
{
  "code": "FILE_NOT_FOUND",
  "message": "File not found",
  "fields": {}
}
```

### 将普通文件作为目录：HTTP 400

```json
{
  "code": "NOT_A_FOLDER",
  "message": "Target is not a folder",
  "fields": {}
}
```

注意：缺失必填 `q`、`page` 不是整数或 `parentId` 无法绑定为 int64 时，由 Spring 框架返回 HTTP `400`；当前实现没有为这些绑定错误统一定义上述业务 JSON 结构，不应假定其错误码也是 `INVALID_SEARCH`。
