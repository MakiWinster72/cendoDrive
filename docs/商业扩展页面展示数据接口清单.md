# 商业扩展页面展示数据接口清单

本文定义 Ula 前端任务 61/62 涉及的商业扩展页面展示数据接口提案，供前后端确认后实现。接口只提供页面展示所需的只读内容，不包含购买、支付、资产发放、游戏奖励或小说阅读业务。

当前仓库没有这些内容接口的后端实现。前端按本文的暂定路径和 DTO 编写调用；后端实现前，页面使用显式标注的演示数据。路径、字段和鉴权规则须由后端确认后再视为正式契约。

## 通用约定

- 前端基础地址使用 `VITE_API_BASE_URL`，默认 `/api`；下文路径均为 `/api` 后的相对路径。
- 成功响应直接返回 JSON DTO，不再额外套 `data`。
- 错误沿用项目格式：`{ "code": "...", "message": "...", "fields": {} }`。
- 以下接口均为只读 `GET`，不要求登录；已登录客户端可能附带 Bearer Token，但接口返回不包含用户私有状态。
- 图片使用浏览器可访问的 `imageUrl`，跳转目标使用应用内相对路径或完整 HTTPS URL；不得返回 FastDFS 内部存储地址。
- 无单条内容时返回 `null`；集合无内容时返回空数组 `[]`，不得用 `null`、空对象或演示数据表示真实空结果。
- 列表按展示顺序返回，前端按服务端顺序渲染。

## 开屏广告

`GET /api/content/splash-ad`

返回当前有效的一条开屏广告；没有有效广告时返回 `204 No Content`。

```json
{
  "id": "ad-2026-01",
  "title": "云端空间焕新",
  "imageUrl": "https://cdn.example.com/ads/splash-01.webp",
  "targetUrl": "/membership",
  "displaySeconds": 4,
  "skipAfterSeconds": 1
}
```

`id` 为字符串。`displaySeconds` 为展示总时长，`skipAfterSeconds` 为允许跳过前的秒数，均为非负整数。`targetUrl` 为空时广告仅展示、不跳转。

前端每个浏览器标签页会话对同一广告 ID 只展示一次；无广告（204）时不遮挡首页。开发模式下接口请求失败会显示带“演示广告”标记的本地素材，生产模式不会用演示广告冒充后端内容。

## 首页及个人页活动展示

`GET /api/content/home`

返回首页会员入口与个人页活动卡片所需的展示文本和跳转信息。

```json
{
  "membershipEntry": {
    "title": "会员免费领",
    "subtitle": "新用户福利",
    "targetUrl": "/membership"
  },
  "profileCampaign": {
    "id": "campaign-01",
    "title": "网盘 SVIP 会员活动",
    "subtitle": "活动领取能力暂未开放",
    "buttonText": "查看方案",
    "targetUrl": "/membership",
    "imageUrl": null
  }
}
```

`membershipEntry` 和 `profileCampaign` 可以为 `null`。这是展示配置，不表示领取、购买或活动资格校验已经实现。

## SVIP 页面展示方案

`GET /api/content/membership`

```json
{
  "plans": [
    {
      "id": "svip-year",
      "name": "连续包年",
      "price": "152",
      "suffix": "/年",
      "originalPrice": "498",
      "badge": "新人立减146",
      "sortOrder": 1
    }
  ],
  "benefitGroups": [
    {
      "id": "ai-services",
      "title": "AI智能服务",
      "columns": ["SVIP", "VIP", "普通用户"],
      "rows": [
        { "label": "AI点数充值", "values": ["赠送点数", "—", "—"] }
      ]
    }
  ]
}
```

`price`、`originalPrice` 使用十进制字符串，避免货币精度问题；`suffix`、`badge` 可为空。套餐和权益是展示内容，不能据此认为支付、订单或权益发放接口存在。

## 游戏中心展示内容

`GET /api/content/games`

```json
{
  "categories": ["热门", "休闲益智", "模拟经营"],
  "games": [
    {
      "id": "game-01",
      "name": "示例游戏",
      "category": "休闲益智",
      "description": "游戏简介",
      "coverUrl": "https://cdn.example.com/games/game-01.webp",
      "targetUrl": null
    }
  ]
}
```

`games` 允许为空；`targetUrl` 为空或未配置时，前端显示游戏详情/下载暂未接入，不启动假下载。

## 小说页面展示内容

`GET /api/content/novels`

```json
{
  "sections": [
    {
      "id": "you-may-like",
      "title": "你可能在找",
      "books": [
        {
          "id": "book-01",
          "title": "示例书名",
          "author": "示例作者",
          "coverUrl": "https://cdn.example.com/books/book-01.webp",
          "description": "推荐简介",
          "targetUrl": null
        }
      ]
    }
  ]
}
```

`sections` 和 `books` 按展示顺序返回。`targetUrl` 未配置时，前端显示书籍详情或阅读能力暂未接入。

## 视频页面的数据来源

当前移动端“视频”页是用户网盘视频库，继续使用现有文件列表、鉴权预览和下载接口，并按文件扩展名筛选视频。不新增独立的视频推荐接口，也不把网盘文件列表混入商业内容 DTO。

## 不属于本文的接口

- AI 点数余额、充值、支付及明细。
- SVIP 下单、支付、订单查询和真实会员状态。
- 我的资产券列表、领取和核销。
- 游戏任务、金币兑换、游戏下载启动。
- 小说导入、阅读、书架持久化。
- AI 语义搜索、Embedding、Milvus 检索及文件索引状态；这些由 Maki、Anna、Landen 等对应分工负责。

## 前端当前处理

前端客户端位于 `frontend/src/api/content.ts`。接口成功后用返回 DTO 更新对应展示；请求失败时保留明确标注的本地演示数据，不把失败伪装成真实接口成功。支付、游戏奖励、小说阅读等未实现能力继续显示“暂未接入”状态。
