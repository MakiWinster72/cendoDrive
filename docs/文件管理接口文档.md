# CendoDrive 文件管理接口文档

## 基本信息

- 开发环境基础地址：`http://localhost:8080`
- 接口前缀：`/api/files`
- 认证：除 Swagger 页面外，所有文件接口都需要 `Authorization: Bearer <token>`
- 时间：`updatedAt` 为 UTC ISO-8601 字符串
- ID：响应中的 `id` 和 `parentId` 为字符串；请求中的 ID 为整数

后端启动后可查看：

- Swagger UI：`http://localhost:8080/swagger-ui/index.html`
- OpenAPI JSON：`http://localhost:8080/v3/api-docs`

## 数据结构

```json
{
  "id": "42",
  "name": "项目文档",
  "kind": "folder",
  "size": 0,
  "parentId": null,
  "updatedAt": "2026-09-29T06:30:00Z"
}
```

`kind` 取值为 `folder` 或 `file`；文件夹的 `size` 为 `0`。

## 获取目录内容

`GET /api/files?parentId={folderId}`

- 不传 `parentId` 时查询根目录。
- 仅返回当前登录用户的数据。

成功响应 `200`：

```json
[
  {
    "id": "42",
    "name": "项目文档",
    "kind": "folder",
    "size": 0,
    "parentId": null,
    "updatedAt": "2026-09-29T06:30:00Z"
  }
]
```

## 新建文件夹

`POST /api/files/folder`

```json
{
  "name": "项目文档",
  "parentId": null
}
```

`parentId` 为 `null` 时在根目录创建。成功返回 `201` 和新建的文件夹对象。

## 重命名

`PUT /api/files/{id}/rename`

```json
{
  "name": "已归档项目"
}
```

成功返回 `200` 和更新后的文件或文件夹对象。

## 移动

`PUT /api/files/{id}/move`

```json
{
  "parentId": 10
}
```

`parentId` 为 `null` 时移到根目录。不允许将文件夹移到自身或它的子孙目录。成功返回 `200` 和更新后的对象。

## 上传

`POST /api/files/upload`，Bearer 认证，`multipart/form-data`：`file`（文件，必填）、`parentId`（整数，可选，省略时为根目录）。最大 100MB，由 Spring multipart 配置限制。成功返回 `201` 和文件对象，`kind=file`、`size` 为实际字节数；文件内容写入 FastDFS，数据库保存 file ID 与 `storage_backend=fastdfs`。名称和父目录校验与新建文件夹一致；上传失败不会返回成功结果。

> 后端须能连接 tracker **和 tracker 返回的 storage 地址:23000**。文件访问始终通过需要登录的 `/api/files` 接口，不公开 FastDFS 原始地址。

## 下载

`GET /api/files/{id}/download`

成功返回 `200`，响应类型为 `application/octet-stream`，`Content-Disposition` 包含 UTF-8 文件名。下载需要数据库记录具有有效 `storage_key`：新上传的文件从 FastDFS 读取；升级前的 `storage_backend=local` 文件仍从 `CENDO_STORAGE_ROOT` 读取。文件夹不能直接下载。FastDFS 下载经过用户权限校验，不要直接向浏览器暴露 storage HTTP URL。

## 错误响应

```json
{
  "code": "NAME_CONFLICT",
  "message": "An item with the same name already exists",
  "fields": {}
}
```

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | `INVALID_INPUT` | 请求字段校验失败 |
| 400 | `INVALID_JSON` | JSON 无法解析 |
| 400 | `INVALID_NAME` | 名称为空、`.`、`..` 或包含路径分隔符 |
| 400 | `NOT_A_FOLDER` | 指定的父目录或目标不是文件夹 |
| 400 | `INVALID_MOVE` | 移动到自身或子孙目录 |
| 400 | `FOLDER_NOT_DOWNLOADABLE` | 尝试下载文件夹 |
| 401 | `UNAUTHORIZED` | 未携带 Token 或 Token 无效 |
| 404 | `FILE_NOT_FOUND` | 文件或文件夹不存在，或不属于当前用户 |
| 404 | `CONTENT_NOT_FOUND` | 文件内容不存在 |
| 409 | `NAME_CONFLICT` | 目标目录已存在同名项 |
| 413 | `MAX_UPLOAD_SIZE_EXCEEDED` | 上传超过 multipart 限制 |
| 503 | `STORAGE_UNAVAILABLE` | 存储服务暂不可用 |

## 名称规则

- 名称去除首尾空格后不能为空。
- 最长 255 个字符。
- 不能是 `.` 或 `..`。
- 不能包含 `/` 或 `\`。
- 同一目录下的名称不能重复，忽略大小写。
