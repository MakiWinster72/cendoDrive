# CendoDrive 文件管理接口文档

## 基本信息

- 开发环境基础地址：`http://localhost:8080`
- 接口前缀：`/api/files`
- 认证：除 Swagger 页面外，所有文件接口都需要 `Authorization: Bearer <token>`
- 时间：`updatedAt` 和 `deletedAt` 为 UTC ISO-8601 字符串
- ID：响应中的 `id` 和 `parentId` 为字符串；请求中的 ID 为整数

后端启动后可查看：

- Swagger UI：`http://localhost:8080/swagger-ui/index.html`
- OpenAPI JSON：`http://localhost:8080/v3/api-docs`

## 数据结构

```json
{
  "id": "42",
  "name": "项目文档",
  "kind": "folder",
  "size": 0,
  "parentId": null,
  "updatedAt": "2026-09-29T06:30:00Z",
  "deletedAt": null,
  "favorite": false,
  "hidden": false
}
```

`kind` 取值为 `folder` 或 `file`；文件夹的 `size` 为 `0`。

## 文件名搜索

`GET /api/files/search?q=合同&scope=all&type=doc&page=0&size=20&sort=time`，Bearer 认证。

| 参数 | 说明 |
| --- | --- |
| `q` | 必填，去除首尾空格后 1～100 字符；不区分大小写的文件名包含匹配 |
| `scope` | `all`（默认，全网盘）或 `folder`（当前目录及所有子目录） |
| `parentId` | 仅 `scope=folder` 时可传；省略表示根目录，目录自身不在其搜索结果中 |
| `type` | `all`（默认）、`folder`、`image`、`video`、`audio`、`doc`、`other`；文件按扩展名分类 |
| `sort` | `time`（默认，修改时间降序）、`name`（名称升序）、`size`（大小降序），均追加 ID 保证分页稳定 |
| `page` / `size` | 页码从 0 开始，范围 0～10000；每页默认 20，允许 1～100 |

返回 `{ "items": [{ "file": FileResponse, "ancestors": [FileResponse], "path": "/工作/资料" }], "total": 21, "page": 0, "size": 20 }`。`ancestors` 为从根到父目录的有序文件夹元数据；`path` 是所在目录路径，根目录为 `/`。`total` 在权限、目录范围、类型和关键词过滤之后计数，越界页返回空 `items`，保留总数。

- 用户 ID 只取认证身份；不接受客户端指定所有者。递归查询只遍历本人可见目录，排除隐藏、已删除项目及其所有后代，孤立或循环树不会进入结果。
- `%`、`_`、`!` 按字面量匹配，使用显式 LIKE 转义及绑定参数；不是通配符或正则搜索。
- 所有格式只搜索文件名：不下载文件、不提取正文、不识别图片或扫描 PDF 文字。没有 Elasticsearch、OCR 或额外索引服务。
- 业务参数校验失败返回 `400 INVALID_SEARCH`；缺失必填参数或参数类型无法绑定时由框架返回 `400`。未认证 `401`；指定目录不存在、不属于本人、已删除或位于隐藏空间时 `404 FILE_NOT_FOUND`；以普通文件作目录仍返回既有 `400 NOT_A_FOLDER`。

## 获取目录内容

`GET /api/files?parentId={folderId}`

- 不传 `parentId` 时查询根目录。
- 仅返回当前登录用户的数据。

成功响应 `200`：

```json
[
  {
    "id": "42",
    "name": "项目文档",
    "kind": "folder",
    "size": 0,
    "parentId": null,
    "updatedAt": "2026-09-29T06:30:00Z",
    "deletedAt": null
  }
]
```

## 新建文件夹

`POST /api/files/folder`

```json
{
  "name": "项目文档",
  "parentId": null
}
```

`parentId` 为 `null` 时在根目录创建。成功返回 `201` 和新建的文件夹对象。

## 重命名

`PUT /api/files/{id}/rename`

```json
{
  "name": "已归档项目"
}
```

成功返回 `200` 和更新后的文件或文件夹对象。

## 移动

`PUT /api/files/{id}/move`

```json
{
  "parentId": 10
}
```

`parentId` 为 `null` 时移到根目录。不允许将文件夹移到自身或它的子孙目录。成功返回 `200` 和更新后的对象。

## 上传

`POST /api/files/upload`，Bearer 认证，`multipart/form-data`：`file`（文件，必填）、`parentId`（整数，可选，省略时为根目录）。最大 100MB，由 Spring multipart 配置限制。成功返回 `201` 和文件对象，`kind=file`、`size` 为实际字节数；文件内容写入 FastDFS，数据库保存 file ID 与 `storage_backend=fastdfs`。名称和父目录校验与新建文件夹一致；上传失败不会返回成功结果。

大于 100 MiB 的文件使用分片接口，协议详见 [`分片上传接口协议.md`](./分片上传接口协议.md)。

> 后端须能连接 tracker **和 tracker 返回的 storage 地址:23000**。文件访问始终通过需要登录的 `/api/files` 接口，不公开 FastDFS 原始地址。

## 下载

`GET /api/files/{id}/download`

成功返回 `200`，响应类型为 `application/octet-stream`，`Content-Disposition` 包含 UTF-8 文件名。下载需要数据库记录具有有效 `storage_key`：新上传的文件从 FastDFS 读取；升级前的 `storage_backend=local` 文件仍从 `CENDO_STORAGE_ROOT` 读取。文件夹不能直接下载。FastDFS 下载经过用户权限校验，不要直接向浏览器暴露 storage HTTP URL。

## 回收站

回收站使用软删除。文件移入回收站后，数据库记录仍然存在，`deletedAt` 保存删除时间；正常目录列表只返回 `deletedAt` 为 `null` 的项目。

### 获取回收站列表

`GET /api/files/trash`

- 返回当前登录用户的回收站项目。
- 结果按删除时间倒序排列。
- 如果已删除项目的父目录也在回收站中，只返回顶层父目录，避免子项重复显示。

成功响应 `200`：

```json
[
  {
    "id": "42",
    "name": "已删除项目",
    "kind": "folder",
    "size": 0,
    "parentId": null,
    "updatedAt": "2026-09-29T06:30:00Z",
    "deletedAt": "2026-09-30T01:20:00Z"
  }
]
```

### 移入回收站

`POST /api/files/trash`

请求体：

```json
{
  "ids": [42, 43]
}
```

- 支持单项和批量操作。
- 所有项目必须属于当前登录用户。
- 操作在同一个数据库事务中执行。
- 已经位于回收站中的项目不能重复删除。

成功返回 `200` 和更新后的文件对象数组，其中 `deletedAt` 已设置。

### 恢复

`POST /api/files/trash/restore`

请求体：

```json
{
  "ids": [42, 43]
}
```

- 支持单项和批量恢复。
- 文件恢复到原目录。
- 如果原父目录仍在回收站中，恢复失败并返回 `PARENT_IN_TRASH`。
- 如果原目录中存在同名项目，恢复失败并返回 `NAME_CONFLICT`。

成功返回 `200` 和恢复后的文件对象数组，其中 `deletedAt` 为 `null`。

### 永久删除

`POST /api/files/trash/delete`

请求体：

```json
{
  "ids": [42, 43]
}
```

- 只允许永久删除已经位于回收站中的项目。
- 删除文件夹记录时，数据库外键会级联删除其子记录。
- 当前接口只删除数据库记录；FastDFS 中实际文件的清理仍需补充。

成功返回 `204 No Content`。

### 清空回收站

`DELETE /api/files/trash`

- 永久删除当前登录用户回收站中的全部项目。
- 不影响其他用户的数据。

成功返回 `204 No Content`。

## 批量操作规则

- `ids` 不能为空，空数组返回 `INVALID_SELECTION`。
- 重复 ID 会自动去重。
- 任一 ID 不存在或不属于当前用户时，整个操作失败。
- 前端只在接口成功后更新状态和显示成功提示。

## 扩展文件管理与容量

以下路径均以 `/api` 为前缀，沿用 Bearer 鉴权和当前用户隔离；文件 ID 使用字符串，根目录 `parentId` 为 `null`。

| 方法 | 路径 | 请求 / 响应 |
| --- | --- | --- |
| GET | `/files/usage` | 返回 `usedBytes`、`limitBytes`、`availableBytes`、`trashBytes`、`reservedBytes`（字节） |
| GET | `/files/folders` | 可用目录列表，用于按完整路径选择目标 |
| GET | `/files/favorites` | 收藏项目列表 |
| GET | `/files/hidden` | 隐藏空间项目列表 |
| GET | `/files/{id}/details` | 返回 `file`、`createdAt`、`path`、`contentSize`、`fileCount`、`folderCount` |
| POST | `/files/move` | `{ "ids": ["42"], "parentId": "7" }`；返回更新后的文件数组 |
| POST | `/files/copy` | 同移动请求；递归复制内容，返回新项目数组，占用额外额度 |
| POST | `/files/favorite` | `{ "ids": ["42"], "value": true }`；`false` 取消收藏 |
| POST | `/files/hidden` | `{ "ids": ["42"], "value": true }`；`false` 移出隐藏空间 |
| POST | `/files/organize` | `{ "ids": ["42"] }`；按扩展名归入类型目录，返回更新后的文件数组 |

- 普通列表 / 最近文件不显示隐藏项目及其后代；隐藏标记不加密内容，也不引入额外密码。
- 移动、复制禁止自身 / 子孙目标，目标须为当前用户的正常目录；同名冲突不覆盖。
- 收藏、隐藏可同时设置多个项目；详情按项目递归汇总内容大小和数量。
- 按类型整理仅移动文件，跳过文件夹，分类为图片、视频、音频、文档或其他。
- `usedBytes` 包含回收站，`availableBytes = max(0, limitBytes - usedBytes - reservedBytes)`；上传预留不是已存文件大小。复制、上传超额返回 `QUOTA_EXCEEDED`，批量递归过多返回 `TOO_MANY_FILES`。

## 错误响应

```json
{
  "code": "NAME_CONFLICT",
  "message": "An item with the same name already exists",
  "fields": {}
}
```

| HTTP | code                       | 含义                                 |
| ---- | -------------------------- | ------------------------------------ |
| 400  | `INVALID_INPUT`            | 请求字段校验失败                     |
| 400  | `INVALID_JSON`             | JSON 无法解析                        |
| 400  | `INVALID_NAME`             | 名称为空、`.`、`..` 或包含路径分隔符 |
| 400  | `NOT_A_FOLDER`             | 指定的父目录或目标不是文件夹         |
| 400  | `INVALID_MOVE`             | 移动到自身或子孙目录                 |
| 400  | `FOLDER_NOT_DOWNLOADABLE`  | 尝试下载文件夹                       |
| 400  | `INVALID_SELECTION`        | 批量操作未选择任何项目               |
| 401  | `UNAUTHORIZED`             | 未携带 Token 或 Token 无效           |
| 404  | `FILE_NOT_FOUND`           | 文件或文件夹不存在，或不属于当前用户 |
| 404  | `CONTENT_NOT_FOUND`        | 文件内容不存在                       |
| 409  | `NAME_CONFLICT`            | 目标目录已存在同名项                 |
| 409  | `ALREADY_IN_TRASH`         | 项目已经位于回收站                   |
| 409  | `NOT_IN_TRASH`             | 对正常项目执行了仅限回收站的操作     |
| 409  | `PARENT_IN_TRASH`          | 恢复项目时，其父目录仍在回收站       |
| 413  | `MAX_UPLOAD_SIZE_EXCEEDED` | 上传超过 multipart 限制              |
| 503  | `STORAGE_UNAVAILABLE`      | 存储服务暂不可用                     |

## 名称规则

- 名称去除首尾空格后不能为空。
- 最长 255 个字符。
- 不能是 `.` 或 `..`。
- 不能包含 `/` 或 `\`。
- 同一目录下的名称不能重复，忽略大小写。

## 当前实现边界

- 普通上传、分片上传与断点续传已实现；上传取消不会立即清除服务端暂存任务。
- 限时分享、分享下载和跨用户独立转存已实现；转存计入接收方配额，并计入未完成上传的预留容量。文件夹 / ZIP 打包下载尚未实现。
- 永久删除在事务提交后尝试清理实际存储文件；失败只记录日志，尚无持久重试队列。
- 隐藏空间不提供加密；按类型整理是扩展名规则，不是 AI 内容分类。
