# 上传限速与模拟会员支付

- 普通用户和会员统一为每个文件 **128 KiB/s（131072 字节/秒）**，不按账号合计。
- `/api/files/upload` 使用限速输入流；`/api/upload/chunk` 在会话数据库行锁内限速读取，因此同一会话的并发分片不会叠加速率。合并、内部复制和头像不重复限速。
- 限制的是服务端文件处理/确认速率，**不是 TCP 瞬时入口带宽**：Servlet/反向代理可能预先缓存 multipart 请求。若需严格网络入口整形，应在代理/网络层另行配置。
- Nginx 仅上传入口使用900秒响应等待（100MiB在128KiB/s下约800秒），其他接口超时保持不变。
- 浏览器上传请求不设固定超时，避免限速后的正常上传被120秒超时中断；原有可取消上传仍使用 AbortSignal。

## 模拟会员

登录后在 `/membership` 选择演示套餐和微信支付，点击立即支付即可模拟开通，成功后仅提示“开通成功”，无需二次确认。模拟金额由后端确定：`trial` 5.8 元、`year` 152 元、`month` 0.6 元（按页面标示数值模拟，不换算周期）。

`POST /api/membership/simulate-payment` 请求示例：

```json
{"planId":"year","paymentMethod":"wechat"}
```

只更新当前认证账号的 `vip_level=SVIP`，持久化到数据库，不设期限。重复请求不会产生额外权益；不扣款、不接入真实微信、不自动续费，不调整存储配额或上传上限。客户端提交的用户ID、金额不能改变目标账号或金额。

这是用户要求的演示功能，默认开启。**公开生产部署前必须设置 `cendo.membership.simulated-payment-enabled=false`**（环境变量 `CENDO_MEMBERSHIP_SIMULATED_PAYMENT_ENABLED=false`），避免用户自行开通会员；正式支付须用服务端支付订单及签名验真的回调，不能沿用此模拟入口。自定义内容接口套餐不属于演示套餐，暂不支持模拟购买。

## 回归测试时限

`FileManagementIntegrationTest#fileLargerThan100MiBUploadsInRealFiveMiBChunksWithoutWholeFileRam` 实际上传101MiB，新限速下仅分片读取需要约808秒。完整 `mvn test` 应预留至少20分钟，而不是240秒；限速单元测试使用虚拟时钟，接口探针使用16KiB实测至少125毫秒。

短时回归可暂排除上述单个长用例（不等价于完整测试全部通过）：

```sh
mvn '-Dtest=*,!FileManagementIntegrationTest#fileLargerThan100MiBUploadsInRealFiveMiBChunksWithoutWholeFileRam' test
```
