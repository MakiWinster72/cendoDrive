# 账号管理接口

除 `POST /api/auth/restore` 外，所有接口需 `Authorization: Bearer <token>`。用户 ID 是十进制字符串，由数据库注册时自动分配，不接受客户端指定本人 ID。修改昵称不修改用户名或 ID。

## 资料与头像

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| `GET /api/user/me/profile` | 无 | 本人资料 |
| `PUT /api/user/me/profile` | `{"nickname":"新昵称"}` | 更新后的资料 |
| `GET /api/users/lookup?username=maki` | 完整用户名，3–64 位字母 / 数字 / 下划线；去空格、忽略大小写 | 可用账号的最小资料；不存在 / 禁用为 404 |
| `GET /api/user/me/avatar` | 无 | `image/png`；无头像为 404 |
| `GET /api/users/{id}/avatar` | 登录后读取可用用户头像 | `image/png`；禁用 / 无头像为 404 |
| `PUT /api/user/me/avatar` | `multipart/form-data`，字段 `file` | 204 |
| `DELETE /api/user/me/avatar` | 无 | 204；重复删除可安全执行 |

资料结构：`{"id":"1","username":"maki","nickname":"新昵称","hasAvatar":false}`。不返回密码哈希、邮箱、配额或会话字段。昵称去首尾空格，长度 1–64，不允许控制字符；查询不支持昵称、模糊匹配或用户列表。

头像按真实内容检测，不信任扩展名 / MIME。只接受 PNG / JPEG，最多 2 MiB、2048×2048；先读取尺寸再解码，居中裁为 256×256 PNG，不保留原图元数据。保存在 `user_avatars`，不计入网盘配额；响应 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`。

## 修改密码

`POST /api/user/me/password`

```json
{"currentPassword":"password123","newPassword":"new-password"}
```

成功 204；当前密码必须正确，新密码与原密码不同，长度 8–72，UTF-8 最多 72 字节。使用 BCrypt 保存，递增鉴权版本，使包括当前设备在内的所有旧会话失效；随后必须重新登录。密码错误返回 400 `INVALID_PASSWORD`，不使用会触发前端全局退出的 401。

## 申请注销

`POST /api/user/me/deletion`

```json
{"password":"password123","confirmation":"注销账号"}
```

成功 200：

```json
{"deletedAt":"2026-10-01T12:00:00Z","purgeAfter":"2026-10-08T12:00:00Z"}
```

立即标记账号不可用、撤销所有旧设备会话和本人分享，用户查询不再公开该账号；文件和账号先保留 7×24 小时。`purgeAfter` 为最早可清理时间，不是物理清理已完成的承诺。用户名在真正清理前仍保留，原分享不可访问，已被他人独立转存的副本不删除。

## 七天内恢复

匿名 `POST /api/auth/restore`（前端不携带旧 Bearer）：

```json
{"username":"maki","password":"password123"}
```

仅当账号处于注销状态且当前时刻严格早于 `deletedAt + 7 天`，验证原密码后返回 204。再次递增鉴权版本，不发 Token；随后调用普通登录。旧分享、旧会话不会复活。到期、账号不存在、密码错误或非注销账号统一返回 401，不泄露账号状态。

## 后台清理与错误

默认每小时从到期账号中取最多 20 个处理；采用账户锁检查到期状态，逐个物理删除存储文件并提交元数据进度，最后删除暂存、头像、分享和账号。包括隐藏空间、回收站及嵌套文件夹。物理存储异常保留未完成记录，下次任务重试；已成功删除的文件不重复处理。服务停机时不会执行任务，恢复运行后继续。默认间隔为 `cendo.user.cleanup-delay-ms=3600000`，示例配置可用 `CENDO_ACCOUNT_CLEANUP_DELAY_MS` 覆盖。

错误体沿用 `code/message/fields`。主要错误：400 `INVALID_PROFILE` / `INVALID_USERNAME` / `INVALID_AVATAR` / `INVALID_PASSWORD` / `INVALID_NEW_PASSWORD` / `PASSWORD_UNCHANGED` / `INVALID_CONFIRMATION`，404 `USER_NOT_FOUND`，401 无效会话 / 恢复失败，429 密码验证过于频繁（与用户名登录限流共用，5 次失败 / 15 分钟）。输入字段约束失败返回通用校验错误。部署层仍需 TLS、CSP、来源限流和审计；禁止记录原密码或完整 Token。
